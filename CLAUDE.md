# Project Rules

## AI Development Workflow

1. Every implementation must begin with a short implementation plan before code is generated.

2. Forms must use React Hook Form with Zod validation instead of manual validation.

3. Every form input must have an associated label and appropriate accessibility attributes.

4. AI-generated code must be reviewed and verified before committing to the repository.

5. New features should include unit tests where practical, and tests should be executed before completion.

6. Use Conventional Commits for every Git commit.

7. Keep components modular, reusable, and focused on a single responsibility.
